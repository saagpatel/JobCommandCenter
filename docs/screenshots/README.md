# Screenshot Capture Plan

## Purpose

This folder tracks which screenshots should exist for portfolio review, release notes, and demo rehearsal. Captures must use sanitized sample data only.

## Capture Rules

- Use stable sample data.
- Hide local filesystem paths unless they are intentionally generic.
- Do not show real OAuth accounts, API keys, Keychain prompts, resumes, cover letters, email addresses, or browser session cookies.
- Include a short caption beside each final screenshot in release or portfolio materials.
- Re-capture screenshots after visible UI changes, major data model changes, or demo script changes.
